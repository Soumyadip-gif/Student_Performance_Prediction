🎓 Student Performance Prediction

A Machine Learning web application that predicts a student's expected exam score based on academic, personal, and educational factors.

🚀 Features
📊 Data preprocessing & analysis
🤖 Linear Regression & Random Forest models
📈 Model evaluation using MAE, RMSE & R²
🌐 Flask-based web application
🎨 Professional responsive UI with animations
🔮 Real-time student performance prediction
🛠️ Technologies

Python • Pandas • NumPy • Scikit-learn • Flask • HTML • CSS • JavaScript • Joblib
